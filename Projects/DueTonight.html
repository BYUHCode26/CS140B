Internet

A global digital place where people can connect with basically anyone with an device.

Web

A source on the internet that allows you to view and access much information about anything that is listed.

How are the Internet and the Web different?

The internet is just an area people's device's can meet and connect in order to communicate. The web is just a huge resource on the Internet that people have access to.

ASCII and Unicode

Both have a code system that we use in order for the computer to convert characters or digits into text, or vice versa. ASCII stands for American Standard Code for Information Interchange. It deals with characters, punctuation, and numbers while Unicode has a code system with those listed, and basically any symbol.

What is UTF-8

UTF-8, also known as Unicode Transformation Format, is used to store text from their designated characters into bytes. This also depends if we are converting characters, punctuations, symbols, etc.

URL

It is basically the links you type in, the web addresses, that specify the webpage, and help determine your location on the internet. It is also known as the Uniform Resource Locator.

Domain Name

It is the usual text we type in order to direct us to the webpage we want. For example: www.MrPresident.org

HTTP

Also know as Hypertext Transfer Protocol. This is what the Web reads in order to determine what webpage you want to view, as well as where to transfer your web information.

HTTPS

It is basically the same as HTTP, except it keeps your information safe. Meaning, you transfer your information somewhere on the Web without losing your data.

IP Address

It is a unique sequence of numbers that identifies a device, or your location of data.

DNS

Also known as Domain Name System where the Web converts the domain name into an IP in order to read, and direct the user to the correct position on the Web.

W3C Recommendations

They are tools the Web uses in order to ensure that the websites are secure and working.

XML, XHTML, HTML, HTML5

These are the main tools the Web uses in order the make the webpages work, and for the users to understand how to use it, and access it. XML is the organizer, XHTML is the structure, HTML is the how the webpages are understandable to humans, and HTML5 is the audio and visuals of the webpages.
