Beginning CSS

Explain the difference between inline, embedded, and external CSS.

  1. Inline CSS relies on adding attributes to tags that are within the same line as the attribute. However, they are recommended not to be used for HTML, because they aren't consistent when it comes to styling webpages.
  2. Embedded CSS relies on making a CSS selector. What this means is that there will be a tag attribute that will select a certain tag, and change that tag that is implemented to have the attribute. It is not as reliable either, because it will only stylize one websheet instead of the full thing.
  3. External CSS uses an external file to provide attributes to all tags of the same function, and this will be true with all webpages supported by the folder that holds all HTML pages. It is considered the most reliable CSS.

Explain why you should only use external CSS.

Like what was mentioned, it is the most reliable in keeping all tags listed to have the same attributes, which is extremely useful, because it helps with other files that aren't shared with your current webpage. By keeping it in an external file, it is very consistent, and efficient.

What is a selector used for?

A selector is used to select a tag with the same type, and by using the selector, you are able to easily change their appearance and attributes just by changing only the selector.
