November 9 Questions

The form tag has an "action" attribute. What does it do?

The Action Attribute takes the data from the "form" and sends that data to the designated webpage, the action attribute locates/directs this webpage.

The form tag has a "method" attribute. What does it do?

The method attribute determines how your data on your form is transported through your URL.

What is the difference between a "POST" and a "GET"?

The method "get" will transport your form data answers in the URL, while the "post" method transfers the data, just not visibly on the URL.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.

A preset value is just text that is already typed and ready in the textbox, while a placeholder text is just text in the textbox, but the textbox is still empty.

  1. Textboxes have placeholders as grey text that disappears once you type actual text in the textbox.
  2. Textarea is about the same thing, just with a larger textbox.
  3. Select Boxes will automatically have a box already checked. Although, there is not a way to use placeholders.
  4. The same goes for radio buttons, but how preset values are for radio buttons are really just buttons already filled as well.

List all the form controls that HTML5 added. Which ones did you put in your form?

I put in the input tag, the textarea, and the button tag of HTML5. These are the main form controls that you can put in your form:

  1. Input
  2. Textarea
  3. Select
  4. Button

November 11 Questions

What are different ways to style your form?

  1. Fieldsets:
      2. Fieldsets are very useful for making your form more organized and easier to categorize information. They appear as borders around the selected data.
  2. Legend
      3. Legends are used to make the title or heading for the fieldsets. These help the reader or user know what is being displayed.
  3. Inputs
      4. You can create the type of information asked from the user, along with how the information can be portrayed.

These can all be stylized the same as any text or tag.

Why does the professor like to use flex?

When it comes to positioning, displaying these as flex can help make styling easier, and organized. Also, flex makes it easier to distribute and place text boxes and text to make it look more professional.

What makes for a good mobile form?

  • All of the buttons on the form have to be big enough for the fingers.
  • The text has to be big enough to be readable
  • The text should also be evenly spaced
  • The form should not have any text overfilling, meaning it cannot cross the relative margin
