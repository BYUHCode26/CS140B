CSS Selectors

List out the different ways to select an item.

  • ID Selectors
  • Class Selectors
  • General Selectors

General Selectors are just selected by typing which tag, or the main four tags, or both. The four tags being header, main, and footer. Nav is just for links.

What is the difference between an ID and a Class?

An ID is very specific when trying to give attributes to a tag. There can only be one tag with an ID name, none can share the same name. On the other hand, a class can is not as specific, because tags with the same class name can still share those attributes.

What is the difference between a SPAN tag and a DIV tag?

The DIV is used to select a section of code while the SPAN tag is used to select a specific line of text in the tag.

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

The main, header, and footer have a purpose when it comes to filling them with information, or commands. The DIV tag is just a generic spacing for text when trying to hold text.

What are the different ways to select a color?

You can name a color by using the hex method where you have the hastag along with 16 characters to choose from. 1-9, and then A-F. Two characters each of these will resemble RGB. The simpler hastag method is where instad of two characters, its just one. It is really just shortened. Finally, the RGB method is where you just use a function, and insert 3 different integers from 1-255. Each integer resembles RGB once again. Also, RGBA, the A being "alpha channel", just just determines the opacity of the RGB colors. The integer for this value is determined by either 1, or 0. Now, this is where you would make it a float number to be spcific of your opacity.
