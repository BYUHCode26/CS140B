Sidebar

These are the six photos of the Laie Temple, and each image is under one folder, or div. The sidebar and page of images are in another folder or div.

Three things that looked wrong or hard to use:

First, the links were to small to press on, so we have to make the links bigger so we don't fat thumb the links. Second, the images were organized terribly when using a mobile device to view images. They looked like they were either too big, or gave us a hard time to navigate. Finally, the images were too chunky, so we had to shrink their size a little bit. Additionally, we needed a breakpoint so the images do not collide with each other when using a mobile device. The breaking point is 600px.

Why do we need a viewport meta tag?

We need a viewport meta tag, because that is how we are able to determine what the website we made would look like on other devices. We are able to compare its appearance from the computer to other devices.

When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

Usually, it is the flex-direction that is written on the bottom of the code, because the bottom code takes priority.

How do you change the CSS for a web page displayed on a phone?

There is a function called "@media" where you can manipulate the CSS code to alter the website under certain conditions when using the website on mobile.

Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.

It changes how big the links are, and it also changes the layout of the images.

What width did you choose for your breakpoint, and why?

I chose to do a width of 600px, because that was when the images started to wrap together with terrible organization. This is to ensure that the images don't take over the entire cover of the phone, leaving you helpless to navigate.
