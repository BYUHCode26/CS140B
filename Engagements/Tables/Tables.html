November 4 Questions

Why don't we use the border attribute?

Noticeably, we had to remove the border attribute in the HTML, because HTML focuses on the structuring of the webpage, while CSS focuses on the presentation of the webpage. Therefore, it is not recommended to use the border attribute specifically for this reason.

What is the easiest way to color every other row a different color?

It is mainly easier to use the structure tags that help structure the table. For example: the "th" tag. Then, you can differentiate subtags with classes, and then change their colors through CSS. That way, it is organized, and easy to look back to when you need to change things.

What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.

The value in the parentheses just specifies what elements you want to be changed. For example, you can manipulate the CSS of structural pseudo-class to make a row on the table red.
