What is normal flow in HTML?

It is the default style of your webpage which is dependent on how your HTML is set and designed. This can can be modified, but otherwise, it will follow the default layout.

What does float do? Why do you need to clear the float?

According to sources, float is a property. Knowing this, a float is helpful for its selected image in creating space for block tags to wrap around the image. This can be helpful in organizing information like newspapers. Clearing a float ensures that your block tags do not also interrupt the organization of your image's space.

What do absolute, fixed, and relative do?

Absolute is when you remove excess space from, for example, an image. Text and other proprties that you would add on to the image would not use up more space. Relative helps keep the excess space provided by the image for example, and is helpful for its own purposes. The fixed function is helpful for keeping the image for example still when you navigate through the webpage, like scrolling.

How can you make nice navigation buttons for mobile devices?

Obviously, you have to have some kind of image to represent the navigation tool, but mainly, your image needs to have the position property using the function: fixed. The fixed property function will keep the image still while you scroll, so it will always show on your screen.
