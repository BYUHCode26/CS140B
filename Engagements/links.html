Explain the difference between an absolute link and a relative link. Why would you use relative links?

An absolute link provides a URL link that will directly take you to the webpage. In order for this to work, all information like link address, and data is needed for direct usuage. Relative links are are links that are only connected to their sibling folder. For example, you don't have to put the entire link address in order to direct your webpage to another, because both webpages have similar folders.

List the 3 rules with relative links.

The first rule is has to do with linking to your folder. When if the file and the page you are going to both are in the same folder, then just write the file name. The second rule is that if they are not in the same folders, then write down the folder name with the file name. The last rule is that if you are going to the next folder, or up the folder, then use the "../" with the file name.
