Structural Tags (HEADER, NAV, MAIN, FOOTER).

These are usually known for organizing the webpage in order to make it more readable, organized, and easy for users to navigate. Each of theses structural tags are used for different parts of the webpage in order to organize your coding as well.

What goes in the header?

Usually some of the navigation links will go in the header, because users are used to accessing navigation links from the main lobby of the webpage. This will usually be the first thing presented. Mainly, the header will have the title, and logo as the main attraction.

What goes in the Nav?

This is mainly where all the links are placed, because the users will use these links to navigate. Like in the name.

Can the Nav go in the header? Does it have to go in the header? Does the Nav contain links to another website?

It can to be more presentable as to how organize, and efficient it is in navigating, but it usually is in the nav tag. They do not have to go in the header. Finally, the Nav does have links to another website, only if the purpose of navigation fits with the website. For example, a school website shouldn't navigate to a gaming website.

What goes in Main?

The Main is the canvas of your website. It includes the page, information of the page, maybe it has appealing images so the users will be tempted to click, this is where all the attraction, and resources take place.

What goes in the Footer?

There are many links, and cpoyrighted information that goes here, because it is considered a legal action. This is mainly important for indexes and additional information, but most importantly, it is to ensure that this website is owned by you.
